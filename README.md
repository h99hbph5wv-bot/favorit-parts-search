# Favorit Parts — поиск запчастей

Клиентское React-приложение для двухэтапного поиска через Web-сервис «Проценка» Favorit Parts.

## Запуск

1. Установите Node.js 18+.
2. Скопируйте `.env.example` в `.env` и укажите выданный Favorit Parts ключ покупателя в `VITE_FAVORIT_API_KEY`.
3. При необходимости задайте доступный вашему аккаунту URL API в `VITE_FAVORIT_API_URL`.
4. Выполните `npm install`, затем `npm run dev`.

Для production-сборки: `npm run build`.

## Работа с API

- При вводе артикула приложение с задержкой 450 мс вызывает `GET /hs/hsprice/?key=…&number=…&info=on` и показывает производителей.
- Выбор производителя вызывает запрос с `brand=…&analogues=on`.
- Предложения формируются из `goods` и вложенных `analogues`; каждая складская строка берёт цену из `warehouses[].price` и наличие из `warehouses[].stock`.
- Ошибки API, сетевые ошибки, пустой ответ и незаданный ключ отображаются в интерфейсе.

В документации API от 06.03.2023 базовый адрес указан как HTTP. Браузерные приложения, открытые через HTTPS, не могут обращаться к HTTP API из-за mixed content; также API может требовать разрешённый CORS origin. Для такого окружения задайте HTTPS endpoint, предоставленный Favorit Parts, либо используйте HTTPS reverse proxy своего backend и укажите его URL в `VITE_FAVORIT_API_URL`. Не размещайте секретный ключ в публичном клиенте без согласования политики доступа с поставщиком.
